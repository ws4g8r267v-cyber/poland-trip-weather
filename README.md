# poland-trip-weather · v0.1

מזג אוויר למסע לפולין, 18–24/11/2026: ורשה, טרבלינקה, מיידנק, אושוויץ-בירקנאו, קראקוב.
עצמאי לגמרי, ואין לו קשר למערכות של העבודה. אין בו מפתחות ואין בו סודות.

## מה יש בריפו
| קובץ | מה הוא עושה |
|---|---|
| `index.html` | המסך. קורא את `data/latest.json` ומציג אותו. |
| `collect.py` | האוסף. ספרייה סטנדרטית של Python בלבד, בלי התקנות. |
| `.github/workflows/collect.yml` | מריץ את האוסף כל 3 שעות, וגם ידנית מלשונית Actions. |
| `data/latest.json` | נכתב על ידי האוסף. לא עורכים ידנית. |
| `data/climate.json` | ממוצע עונה 2016–2025. נבנה פעם אחת ולא יורד שוב. |

## מקורות
- **MET Norway** locationforecast 2.0 (CC BY 4.0): התחזית הראשית.
- **Open-Meteo** (CC BY 4.0): השוואת מודלים ICON / ECMWF / GFS, וממוצע עונה מהארכיון.
- **NOAA AviationWeather METAR**: מדידה בפועל ב-EPWA, EPKK, EPLB.

כשל במקור אחד לא מפיל את האחרים. אתר או תחנה שנכשלו שומרים את הנתון הקודם שלהם, והמסך מסמן אותו כ"לא עודכן".

## יחידות
°C · מ"מ · קמ"ש (יבשה). הימים והשעות לפי שעון פולין (UTC+1 בנובמבר; ישראל UTC+2).

## מצבי המסך
1. **ממוצע עונה**: לפני שיש תחזית לימי המסע (בערך עד 03/11).
2. **תחזית**: כל יום עובר לבד ברגע שיש לו תחזית. התחזית אמינה בערך שבוע לפני.

## בהמשך (לא ב-v0.1)
- סדר האתרים לפי ימים, מתוכנית המסע.
- הודעת בוקר לקבוצת הוואטסאפ, ממספר נפרד.
